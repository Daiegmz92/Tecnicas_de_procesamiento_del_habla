# Notebooks de Modelos de Lenguaje en Español 🇦🇷🧠

Este repositorio contiene una serie de notebooks diseñados para explorar y experimentar con modelos de lenguaje en español, con foco en el modelo **Phi-3-mini** desarrollado por Microsoft. Cada notebook tiene un enfoque didáctico y local, adaptado al contexto argentino.

---

## 📘 Contenido

### 1. `Intro_Modelos_Lenguaje_Phi3_Ejercicios.ipynb`

Una introducción amigable al uso de modelos de lenguaje con ejercicios prácticos.  
Incluye ejemplos culturales, recetas y modismos porteños.

**Temas tratados:**
- ¿Qué es un modelo de lenguaje?
- Uso básico del modelo Phi-3 en español
- Generación de texto contextualizada
- Ejercicios con prompts culturales argentinos

---

### 2. `Explorando_Modelos_Transformer.ipynb`

Notebook teórico-práctico para entender cómo funciona internamente un modelo tipo Transformer.

**Temas tratados:**
- Arquitectura de modelos como Phi-3
- Decodificación de tokens y predicción
- Eficiencia con y sin uso de caché
- Análisis paso a paso de cómo generan texto

---

### 3. `Tokenizacion_y_Embeddings_Modelos_LLM.ipynb`

Explora cómo los modelos procesan texto a nivel de tokens y cómo obtener **embeddings** útiles para tareas de análisis semántico.

**Temas tratados:**
- Tokenización comparada entre modelos
- Colores para visualizar tokens
- Embeddings contextuales (DeBERTa)
- Embeddings de oraciones (Sentence Transformers)

---

## ⚙️ Requisitos

- Google Colab o Jupyter Notebook con acceso a GPU
- Python 3.10+
- Bibliotecas: `transformers`, `accelerate`, `sentence-transformers`, `scikit-learn`, `gensim`, `numpy`, `scipy`

---

## 📌 Cómo usar

1. Subí estos notebooks a tu entorno (Colab, Jupyter, etc.)
2. Asegurate de tener una GPU activa (en Colab: `Entorno > Cambiar tipo > GPU`)
3. Ejecutá cada celda paso a paso
4. Modificá los prompts y observá los resultados en español
