# Proyectos con Gradio - Colección de Interfaces Interactivas de IA

Esta carpeta contiene tres notebooks/proyectos diferentes que usan **Gradio** para crear interfaces web interactivas de aplicaciones de inteligencia artificial basadas en procesamiento de lenguaje natural (PLN) y modelos generativos.

---

## Proyectos Incluidos

### 1. Demo Básica con Gradio

- Interfaz sencilla para saludar al usuario por nombre.
- Introducción básica al uso de Gradio.
- Funcionalidad: recibe texto y devuelve un saludo personalizado.

---

### 2. Sumador Visual con Gradio

- Aplicación simple con múltiples entradas numéricas.
- Funcionalidad: suma dos números ingresados y muestra el resultado.
- Introduce el manejo de diferentes tipos de input y output en Gradio.

---

### 3. Clasificador de Sentimientos en Español

- Clasificador básico de sentimiento “dummy” con reglas simples.
- Clasificador avanzado usando modelos de Hugging Face entrenados en español (`pysentimiento/robertuito-sentiment-analysis`).
- Funcionalidad: clasifica texto en positivo, negativo o neutral y muestra confianza.
- Incluye ejemplos y despliegue usando Gradio con posibilidad de compartir.

---

## Tecnologías Usadas

- **Python 3.7+**
- **Gradio** para creación rápida de interfaces web.
- **Transformers (Hugging Face)** para modelos de lenguaje y análisis de sentimientos.
- Modelos específicos entrenados para español y contexto latinoamericano.

---

## Cómo Ejecutar

1. Cloná o descargá esta carpeta.
2. Abrí el notebook que quieras ejecutar en Google Colab o tu entorno local.
3. Instalá las dependencias (por ejemplo `pip install gradio transformers`).
4. Ejecutá las celdas en orden para correr la interfaz web.
5. Interactuá con las aplicaciones directamente en tu navegador.
6. En algunos casos, podrás compartir la interfaz pública con Gradio (opción `share=True`).

---

## Recomendaciones

- Para mejor performance, usá un entorno con GPU.
- Modificá y personalizá los prompts o funciones para adaptarlos a tus necesidades.
- Explorá la documentación oficial de [Gradio](https://gradio.app/) y [Hugging Face](https://huggingface.co/docs/transformers/index) para ampliar funcionalidades.
